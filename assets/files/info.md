# Nextflow

## Open source Nextcloud client

![logo nextcloud](assets/images/Nextcloud-logo-blue-small.png)

### Cloud workflow: Up, down and share

**Cliente multicuenta de Nextcloud para Linux y Android.**

Software libre de código abierto.

Seguridad y privacidad: contraseña encriptada que se almacena en local.

### Funciones:

#### Archivos

✅ Navegar por el árbol de carpetas.

⬜ Visualizar varios formatos: imágenes, texto plano, pdf y markdown.

⬜ Descargar y subir.

⬜ Renombrar, mover y copiar archivos.

⬜ Eliminar.

⬜ Crear directorio.

⬜ Mover y copiar archivos entre distintas cuentas.

⬜ Sincronizar.

#### Compartidos

⬜ Visualizar en navegador.

⬜ Copiar enlace.

⬜ Subir archivos y carpetas.

#### Notas

⬜ Visualizar notas.

⬜ Filtrar notas por categoría y favoritas.

⬜ Editar y eliminar notas.

⬜ Crear nota.

#### Galería

⬜ Visualiza los archivos de imagen (ordenados por nombre o fecha).

⬜ Muestra detalles del archivo.

⬜ Descarga.

⬜ Comparte.
